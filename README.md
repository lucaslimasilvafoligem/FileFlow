# FileFlow
FileFlow is a distributed platform for file ingestion, storage and asynchronous processing, supporting images, audio transcription, video processing and document extraction

O projeto deve demonstrar domínio de:

* Java 21;
* Spring Boot 3.x;
* Spring MVC;
* Clean Architecture;
* Clean Code;
* SOLID;
* Design Patterns quando realmente necessários;
* REST API;
* AWS S3;
* MinIO;
* abstração de storage;
* processamento assíncrono;
* filas persistentes;
* concorrência;
* idempotência;
* resiliência;
* segurança;
* Angular;
* TypeScript;
* Design System;
* Docker;
* Docker Compose;
* OpenTelemetry;
* Grafana;
* Prometheus;
* Loki;
* Tempo;
* testes unitários;
* testes de integração;
* Checkstyle;
* análise estática;
* CI/CD;
* documentação técnica;
* UML;
* System Design.
